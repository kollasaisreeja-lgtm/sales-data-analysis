Sales Data Analysis Report

1. Project Overview

This project analyzes sales data using Python and Pandas.

2. Tools Used

- Python
- Pandas
- VS Code

3. Dataset Description

The dataset contains Date, Product, Quantity, Unit_Price, and Total_Sales columns.

4. Data Cleaning

- Converted numeric columns.
- Handled missing values.
- Removed duplicate records.
- Removed invalid negative values.

5. Analysis

- Total revenue
- Total units sold
- Average sale value
- Revenue by product
- Best-performing product

6. Conclusion

This project demonstrates how Python and Pandas can be used to analyze sales data and understand product performance.

7. How to Run

1. Install dependencies using "python3 -m pip install -r requirements.txt".
2. Run the program using "python3 sales_analysis.py".
3. View the results in the Terminal.
